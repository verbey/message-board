# Message Board

## Overview

This application lets the user interact with a _very_ basic NodeJS message board. The user could post new messages and view separate posts on respective pages. It does NOT use a database, the messages are stored in the server's RAM. Made as a part of [the Odin Project course](https://www.theodinproject.com/lessons/node-path-nodejs-mini-message-board).

## Code

The code is pushed to both [Codeberg](https://codeberg.org/Verbiturum/message-board) and [Github](https://github.com/verbey/message-board).

## Setup instructions

1. Open terminal in the directory you want to clone this into.
2. Run `git clone git@codeberg.org:Verbiturum/message-board.git`.
3. `cd` into the cloned repository with `cd message-board`.
4. Run `npm install` to install dependencies.
5. Run `node index.js` to deploy the project on port 3000 (by default).
6. Open https://localhost:3000 in your browser.
